Test native HTTP 402 Payment Required microtransactions over Algorand. Accessing protected endpoints without an on-chain transaction returns standard 402 headers and payment QR URIs.

⚙️ Request Controller
HOW x402 FOR ALGORAND WORKS:
  1. Client requests resource without authorization.
  2. Server returns HTTP 402 Payment Required with WWW-Authenticate, X-402-Amount, X-402-Receiver, and algorand:// URI.
  3. Client signs payment transaction with cryptographic challenge in the note field.
  4. Client retries request with header X-402-Payment-Authorization: txid=<TXID>.
  5. Server verifies transaction on Algorand node/indexer and returns HTTP 200 OK.
